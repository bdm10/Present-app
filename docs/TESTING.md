### Bugs CI found and that are now fixed
1. **FFmpeg 8 (Homebrew/macOS) rejected `-filter_complex_script`**, so music never rendered and sessions retried indefinitely. Fixed by passing the filter graph inline.
2. **The keyboard covered the Save button** on the reflection screen. Save and "Just sit with it" now stay above the keyboard.
